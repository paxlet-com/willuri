# Dokumentacja willuri — Standardy Wellmanifest

Indeks dokumentacji technicznej i architektonicznej modułu `willuri`, opracowany zgodnie ze standardami `wellmanifest/docs`, `wellmanifest/logs` oraz `wellmanifest/wellman`.

## Dokumenty informacyjne (`docs/INFORMATION/`)

- [Narzędzia Operacyjne, Prowizjonowanie i Utrzymanie Usług Willman](INFORMATION/OVERVIEW.md) — przegląd modułu, architektura i integracja w ekosystemie.

## Standardy referencyjne

- **`wellmanifest/docs` v2**: profil dokumentów kompaktowych (`schema: wellmanifest.docs/document/v2`).
- **`wellmanifest/worktrees` v1**: ochrona gałęzi i izolacja worktrees (`worktree-guard.yaml`).
- **`wellmanifest/logs` v1**: ustrukturyzowany kontrakt logowania i katalog błędów w `errors/`.
- **`wellmanifest/wellman`**: ujednolicony runtime standardów Wellmanifest.
